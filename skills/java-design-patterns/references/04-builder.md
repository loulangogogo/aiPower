# 04. Builder

> **Category**: Creational  
> **Intent**: Separate the construction process of a complex object from its representation, so that the same construction process can create different representations.

## Usage

The builder splits the construction of a complex object into several steps and finally calls `build()` once. A common form is a static nested Builder class: required parameters go into the constructor, optional parameters are set through chained methods, and `build()` validates them and returns an immutable object.

1. Define the product class and make its fields `final` wherever possible.
2. Define a Builder inside the class to collect required and optional parameters.
3. Make every setter return `this` to support chained calls.
4. Validate parameters in `build()` and create the product.
5. Let the client combine parameters as needed and call `build()` to obtain the final object.

## Use Cases

- Complex objects with many parameters and optional parameters that are easy to pass in the wrong position.
- HTTP requests, orders, SQL queries, configuration objects.
- Objects that must be built step by step and remain immutable.

## Pros

- The construction process is readable, and parameter meanings are clear.
- Supports immutable objects.
- Validation is centralized, avoiding half-built objects.
- The same construction process can produce different representations.

## Cons

- More code, since an extra Builder is required.
- Using it for simple objects feels cumbersome.
- It may duplicate builders generated by tools such as Lombok.

## Java Example

```java
// Product class: all fields are immutable and can only be created through the Builder
final class Order {
    private final String orderId;
    private final String product;
    private final int quantity;
    private final String coupon;
    private final boolean giftWrap;

    // Private constructor: only the Builder may call it
    private Order(Builder builder) {
        this.orderId = builder.orderId;
        this.product = builder.product;
        this.quantity = builder.quantity;
        this.coupon = builder.coupon;
        this.giftWrap = builder.giftWrap;
    }

    // Return the text representation of the order for demonstration output
    @Override
    public String toString() {
        return "Order " + orderId
                + ": product=" + product
                + ", quantity=" + quantity
                + ", coupon=" + (coupon == null ? "none" : coupon)
                + ", gift wrap=" + (giftWrap ? "yes" : "no");
    }

    // Static nested Builder: collect parameters step by step and validate them
    public static class Builder {
        private final String orderId;
        private final String product;
        private int quantity = 1;
        private String coupon;
        private boolean giftWrap;

        // Create a Builder with two required parameters
        public Builder(String orderId, String product) {
            this.orderId = orderId;
            this.product = product;
        }

        // Set the purchase quantity
        public Builder quantity(int quantity) {
            this.quantity = quantity;
            return this;
        }

        // Set an optional coupon
        public Builder coupon(String coupon) {
            this.coupon = coupon;
            return this;
        }

        // Set whether gift wrapping is used
        public Builder giftWrap(boolean giftWrap) {
            this.giftWrap = giftWrap;
            return this;
        }

        // Validate parameters and create the immutable order object
        public Order build() {
            if (orderId == null || orderId.isBlank()) {
                throw new IllegalArgumentException("Order ID must not be blank");
            }
            if (product == null || product.isBlank()) {
                throw new IllegalArgumentException("Product name must not be blank");
            }
            if (quantity <= 0) {
                throw new IllegalArgumentException("Quantity must be greater than 0");
            }
            return new Order(this);
        }
    }
}

public class BuilderDemo {
    // Entry point: assemble an order with a chained Builder
    public static void main(String[] args) {
        Order order = new Order.Builder("A001", "Mechanical keyboard")
                .quantity(2)
                .coupon("NEW10")
                .giftWrap(true)
                .build();

        System.out.println(order);
    }
}
```
